# Alandas Project Resources

This folder holds supporting materials that are not part of the live System 1 runtime.

- `archives`: zipped exports and bundled reference assets.
- `catalogs`: product and catalog source text.
- `decks`: PowerPoint presentation files.
- `diagrams`: Excalidraw and SVG architecture diagrams.
- `html_exports`: exported HTML presentations and viewers.
- `personas`: persona and stakeholder files.
- `proof_images`: page proofs and temporary visual checks.
- `reports`: PDFs, audits, and written reports.
- `skills`: local skill files and skill lock metadata.
- `strategy_docs`: planning, battle cards, and system strategy documents.

Runtime files remain outside this folder so deployment stays easy to read.
