# Alandas System 1 Access Checklist

Send this to Sidy after payment is confirmed.

## Payment

- EUR 100 service start
- up to EUR 60 tool budget
- no extra paid tool spend without approval

## Screenshots first

Please send screenshots of:

- Meta Business Suite home
- Ad Center
- Lead Center
- connected Instagram account list
- connected Facebook page list
- any page that shows business verification status

Screenshots are safer than screen sharing at this stage. They let us see the setup without touching anything.

## Accounts needed

### Shopify

Needed only for storefront fixes.

Access needed:

- collaborator invite or staff access
- products
- pages
- theme settings
- apps
- analytics pixels if available

Do not send passwords in chat.

### Dolibarr

Needed for CRM and invoice repair.

Access needed:

- staging account if available
- admin or API user
- API endpoint URL
- API key through a secure channel
- database backup location
- sample invoice PDF
- sample customer record
- sample order from WhatsApp photo or voice note

### Hetzner

Needed if we deploy any worker or backup job.

Access needed:

- server IP or hostname
- OS type
- SSH user
- whether Docker is installed
- backup status
- allowed ports
- current apps running on the server

### Instagram and Facebook

Needed for inbound comments and future OpenReply setup.

Access needed:

- B2B Instagram handle
- B2C Instagram handle
- linked Facebook page names
- screenshot showing account roles

## Safety rule

Production changes wait until:

- payment is received
- access is confirmed
- backup path is known
- Sidy approves the first action

The first job is to see the wiring before touching the fuse box.
